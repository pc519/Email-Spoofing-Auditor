# 🛡️ Email Spoofing & DMARC Auditor
A Python security auditing tool that inspects DNS records (SPF & DMARC) to detect email spoofing vulnerabilities and generates client-ready HTML reports with remediation instructions.

# أداة فحص انتحال البريد الإلكتروني
أداة بايثون لفحص سجلات حماية البريد الإلكتروني (SPF و DMARC) واكتشاف ثغرات انتحال الهوية، مع توليد تقرير HTML احترافي يتضمن الحل المقترح.
